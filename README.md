# Secure House Wrapper

A responsive smart-home security dashboard made with HTML, CSS and vanilla JavaScript.

## How to run

1. Open the project folder.
2. Double-click `index.html`.
3. The dashboard opens in your browser.
4. No terminal, npm, React or build step is required.

## Features

- Responsive dashboard
- Demo security toggle
- Interactive device controls
- Emergency contact list saved in browser storage
- Activity history
- Settings page
- Demo login page

## Important

This is a frontend learning project. It does not connect to real cameras,
alarms, door locks, emergency services or a backend.
